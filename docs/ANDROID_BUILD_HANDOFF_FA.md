# تحویل ساخت اندروید – نسخه ۲.۱.۲ آزمایشی

## وضعیت واقعی

- سورس Java/WebView اندروید و Gradle به‌روز است؛ **APK در محیط حاضر ساخته نشده** زیرا Android SDK و Gradle در سیستم موجود نبوده و دسترسی دانلود نیز خطای DNS داشت.
- نسخه کاربر Android 16 و حداقل نسخه هدف اپ Android 7.0 است (minSdk 24 / compileSdk 35 / targetSdk 35).
- اپ اندروید کلاینت رابط شرکت است؛ برای آزمون و مدیریت **سرور Python/SQLite فعال** لازم است. دیتابیس یا کلید پاسخ داخل APK نیست.

## ساخت آزمایشی با GitHub Actions

1. در GitHub **یک مخزن خصوصی مستقل و جدید** صرفاً برای این برنامه ایجاد کنید. پروژه را در مخزن‌های دیگر قرار ندهید.
2. محتوای همین پوشه `miz-mosahebe` را در ریشه مخزن جدید آپلود کنید؛ فایل `.github/workflows/build-internal-release.yml` باید در مخزن باشد.
3. در تب **Actions**، گردش‌کار **Android internal Release APK (temporary test signature)** را با **Run workflow** اجرا کنید (یا آن را با push به main فعال کنید).
4. پس از سبز شدن اجرا، در **Artifacts** فایل `Miz-Mosahebe-2.1.2-INTERNAL-RELEASE-APK` را دریافت کنید؛ ZIP داخل آن حاوی `app-release.apk` و SHA-256 است.
5. روی دستگاه مجاز نصب کنید. **هر اجرا کلید امضای متفاوتی می‌سازد**؛ برای ارتقا به اجرای جدید باید نسخه آزمایشی قبلی را حذف کنید (داده‌های محلی آن پاک می‌شود؛ داده سرور مستقل است).

## انتشار واقعی و ارتقای بدون حذف

- workflow مجزای `build-signed-release.yml` تنها با چهار GitHub Secret معتبر کار می‌کند: `MIZ_KEYSTORE_BASE64`, `MIZ_STORE_PASSWORD`, `MIZ_KEY_ALIAS`, `MIZ_KEY_PASSWORD`.
- کلید امضای پایدار باید در محلی امن و با پشتیبان رمزگذاری‌شده نگهداری شود؛ هرگز آن را commit نکنید. انتشار، ثبت در مارکت یا تولید این اسرار در این مرحله انجام نشده است.
- نسخه Release فقط URL دارای `https://` و گواهی معتبر را قبول می‌کند. سرور محلی با HTTP صرفاً در Debug تست می‌شود.
- جهت نصب روی گوشی، لازم است سرور شرکت در آدرس HTTPS قابل دسترسی باشد؛ بدون آن پوسته اندروید صفحه اتصال نمایش می‌دهد، نه آزمون آفلاین.

## آزمون‌های باقی‌مانده

ساخت واقعی در GitHub/Android SDK، نصب روی Android 16، آزمون دریافت و چاپ CSV، مسیر اتصال TLS، چرخه ۱۰۰ سؤال با سرور واقعی، ارتقا از کلید امضای پایدار و تست امنیت سازمانی هنوز باید انجام شوند.

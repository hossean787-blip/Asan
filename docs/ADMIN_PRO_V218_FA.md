# آسان — بهبود مدیریت نسخه ۲.۱.۸ آزمایشی

## تغییرات
- داشبورد خلاصه عملکرد و آمار عملیاتی مصاحبه‌ها
- سه تب مدیریت: داشبورد، داوطلبان، تحلیل آزمون
- جست‌وجوی زنده نام، موبایل، شناسه آزمون؛ فیلتر موقعیت/وضعیت؛ مرتب‌سازی نمره و تاریخ
- پرونده داوطلب همراه با یادداشت ارزیابی، ثبت وضعیت استخدامی دستی، پاسخنامه و گزارش PDF
- ذخیره وضعیت و یادداشت به‌صورت آفلاین جدا از سوابق آزمون، با حفظ شناسه‌های ذخیره‌سازی قدیمی
- پالت رنگ سبز #50C787 و سفید و نمایش مناسب موبایل/تبلت/دسکتاپ

## کنترل محلی اجراشده
- آزمون نحوی JavaScript با Node
- پنج آزمون قرارداد مدیریت
- Playwright در ۳ اندازه 390×844، 768×1024، 1200×950: داشبورد، فیلترها، جست‌وجو، مرتب‌سازی، ثبت یادداشت و وضعیت، پاسخنامه، تحلیل، خروج و قفل؛ بدون خطای JS
- آزمون جریان قبلی ۱۰۰ سؤال ۲۰ دقیقه‌ای در ۳ اندازه موبایل نیز به‌صورت جداگانه روی بیلد مبنا موفق بود؛ تغییرات مدیریت فرایند آزمون را هدف نگرفته‌اند

## محدودیت‌ها
- داده‌های این نسخه با localStorage داخل برنامه و فقط روی همان دستگاه نگهداری می‌شوند و PIN محلی جایگزین امنیت سرور نیست.
- بانک سؤال نمونه عمومی است و برای تصمیم‌گیری استخدامی رسمی تأیید نشده است.
- ایجاد و اجرای فایل APK باید در GitHub Actions کنترل شود و آزمون نصب روی گوشی به‌صورت جداگانه ضروری است.

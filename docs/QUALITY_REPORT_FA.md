# کنترل کیفیت نسخه ۲.۱.۰ بتا — ۲۰۲۶/۱۱/۰۸

## وضعیت: تکمیل و آزموده‌شده

- ۱۳ آزمون خودکار سرور (unittest) موفق شدند؛ شامل آزمون ۱۰۰ سؤالی، پوشش هر ۲۵ حوزه، جلوگیری از نمایش کلید، حفظ پاسخ‌ها، ورود اتمیک، ابطال کد، تاریخچه تأیید سؤال، قفل بانک به سؤالات تأییدشده، تداوم جلسات قدیمی، CSV و پشتیبان SQLite/WAL.
- بانک هدف JSON: ۳٬۰۰۰ (۹۰۰/۱۲۰۰/۹۰۰)؛ بانک فعلی: ۲۰۰ پیش‌نویس یکتا (۵۰/۷۵/۷۵). همه دارای چهار گزینه متمایز و یک کلید ذخیره‌شده؛ ۵۰ سؤال سناریومحور جدید نگارش شده‌اند.
- ۶ تصویر از اجرای کد واقعی HTML/CSS/JS با API شبیه‌سازی‌شده در Playwright/Chromium، بدون خطای JavaScript. تصاویر شامل داشبورد دسکتاپ/موبایل، ورود سؤال، فرم ساخت آزمون، نمای داوطلب موبایل و فرم بررسی سؤال هستند.
- آزمون دسترسی HTTP تأیید کرد که پاسخنامه و تأیید سؤال بدون نشست مدیر قابل دسترسی نیست؛ آزمون ابطال کد ورود داوطلب را بعد از ابطال رد کرد.
- آزمون سازگاری نشان داد اجرای جلسات نسخه ۲ با بانک اصلی ۱۵۰ سؤالی می‌تواند ادامه یابد؛ سؤالات جدید به‌صورت غیرمنتظره به جلسات فاقد snapshot تحمیل نمی‌شوند.
- پشتیبان SQLite Online Backup با بررسی `PRAGMA integrity_check=ok` و تأیید تعداد جلسات و پاسخ‌ها در دیتابیس بازیابی‌شده تست شد.

## متوقف به‌دلیل مانع

- ساخت و امضای APK: Android SDK/Gradle در محیط موجود نبود؛ DNS/دریافت بسته‌های SDK نیز برقرار نشد. سورس اندروید و workflow حاضرند ولی هیچ APK واقعی ایجاد یا نصب نشده است.
- آزمون کامل مرورگر در اتصال زنده به سرور: مرورگر Chromium در محیط برای بارگذاری آدرس محلی پاسخ صفحه ارائه نکرد؛ بنابراین فقط تست HTTP واقعی در Python و UI با API شبیه‌سازی‌شده انجام شد.
- تأیید علمی مستقل برای ۲۰۰ سؤال، تألیف ۲٬۸۰۰ سؤال باقیمانده، پایلوت استخدامی، سنجش پایایی و کالیبراسیون درجه سختی انجام نشده است.
- تست مستقیم دستگاه، امنیت عملیاتی وب، و امنیت end-to-end با HTTPS واقعی انجام نشده است.

## معیارهای پذیرش نسخه بعدی

۱. مرور تخصصی و تأیید هر ۲۰۰ سؤال با منابع و تاریخ اعتبار؛ تکمیل بانک تا ۳٬۰۰۰ و آزمون پوشش هر سطح.
۲. راه‌اندازی سرور HTTPS و محدودیت نرخ درخواست‌ها/کنترل‌های امنیتی مناسب استفاده شرکتی.
۳. اجرای workflow Release با کلید امضای اختصاصی و انجام آزمون نصب/ارتقا/فرم/تکمیل آزمون روی دستگاه Android.
۴. اجرای End-to-End با مرورگر متصل به سرور واقعی، آزمون بازیابی در زیرساخت مقصد و ممیزی حریم خصوصی.
